# 本机与手机演示

本机地址：`http://127.0.0.1:8081`。Duncan pro 使用独立的 `duncanpro` Docker Compose 项目和数据卷，不占用原版的 8080，也不修改“筑标台”。

## 手机临时链接

安装官方 `cloudflared` 后，双击根目录 `启动手机演示.bat`。脚本会让你输入允许收验证码的邮箱，只将 `127.0.0.1:8081` 通过临时 `trycloudflare.com` 地址发布。无邮箱白名单或管理员仍为默认密码时，禁止启动。每次启动地址都会变化；演示期间电脑、Docker 和脚本窗口均需保持运行。关闭链接可关闭脚本窗口。

手机关闭 Wi-Fi，用移动网络打开临时链接 → 邮箱验证码 → Duncan pro 登录 → 查看同一项目与报告。登录邮箱为 `admin@bidmaster.pro`；双击根目录 `查看演示密码.bat` 可在本机查看随机密码。需要现场离线备用时，先在手机上下载真实生成的 HTML 报告，或将 `samples/Duncan-pro-真实招标解读报告.pdf` 传到手机。

Cloudflare Quick Tunnel 只用于演示，不保证持续在线；邮箱验证码保护依赖其 `--allowed-mail` 选项。参考 [Cloudflare 官方文档](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)。
