# 项目结构与修改入口

| 要改什么 | 入口 | 约束 |
| --- | --- | --- |
| 品牌、登录、侧栏、手机页面 | `packages/desktop/renderer/src/pages/LoginPage.tsx`、`components/layout/`、`styles/globals.css` | 品牌图片在 `renderer/public/duncan-avatar.jpg` |
| 文件上传与解析 | `services/routers/interpret.py`、`core/doc_engine/parsers/` | 无文字层 PDF 必须明确提示 |
| AI 解读维度与提示词 | `services/interpret/skills/tender_interpret_skill.py` | 只依据原文件，失败不能当成功 |
| 报告导出 | `services/interpret/skills/interpret_export_skill.py`、`InterpretPage.tsx` | 保留来源和免责声明 |
| 启动与模型配置 | `docker/docker-compose.duncan.yml`、`.env.local` | 密钥永不入库；新数据卷与原项目隔离 |
| 演示素材 | `samples/` | 公开来源，本地文件不打进镜像或源码包 |

每次修改先在对应专题聊天说明目标；在独立 Git 分支或提交中完成。修改后重新构建所涉及的服务，并检查上传、解析、解读和报告链路。重大功能另开专题，避免一次改动跨越无关模块。
